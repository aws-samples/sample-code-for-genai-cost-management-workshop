# Sample Code

This folder contains code samples for the workshop, organized into two parts:

- **[1-track/](1-track/)** — cost attribution: know *who is spending what, and where*
- **[2-optimize/](2-optimize/)** — cost reduction: spend less without sacrificing quality, from low-effort tweaks to high-effort architecture changes

## Track

Attribution methods that show you where your generative AI spend goes. See [1-track/](1-track/) for the full list of methods and the tag naming convention.

## Optimize

Cost-reduction levers that lower your bill once you can see where it goes. See [2-optimize/](2-optimize/) for the samples, organized into low-, medium-, and high-effort tiers.
